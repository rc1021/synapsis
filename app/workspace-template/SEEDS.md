# Seeds

> **Externally we say "seeds", internally we run "neurons".**
>
> Each entry is a node. Watering doesn't grow a single tree — it strengthens the entire network's connection density.
> Nodes connect, branch, go dormant, and get re-activated.

## Status definitions

| Seed language | Neuron language | Symbol | Meaning |
|---------------|----------------|--------|---------|
| Planted | New node | ⚡ | Fresh idea, not yet explored |
| Growing | Extending synapses | 🔗 | Starting to connect with other nodes |
| Blooming | Firing | 💡 | Produced something (note, work, insight) |
| Fruiting | Myelinated | 📡 | Applied in practice, repeatedly validated |
| Dormant | Silent synapse | 😴 | Connection exists, just not triggered |
| Regenerating | Branching | 🌱 | New node growing from an existing one |
